# Судоку без рекламы и без угадывания

Личная игра владельца для телефона (Android). Сейчас — веб-приложение (PWA), которое ставится
с GitHub Pages на главный экран как обычное приложение и работает без интернета.
Следующий этап — упаковать его в настоящее Android-приложение (APK).

## Закон игры (требования владельца — не нарушать)

1. **Никакого угадывания.** Каждая головоломка перед показом решается встроенным «решателем как человек»
   (`js/logic.js`) только логическими приёмами. Не решилась — в игру не попадает. Решение всегда одно.
2. **Уровень = самый трудный приём, который понадобился** (шкала в духе Sudoku Explainer), а не число пустых клеток.
3. **Ошибки не наказываются.** Нет счётчика ошибок и проигрыша. Повтор цифры только подсвечивается красным.
   Есть «Отменить» и «Стереть», повторное нажатие той же цифры убирает её.
   Игра никогда не сверяет ход со скрытым ответом — подсказывает только то, что видно на доске.
4. **Автоматика, экономящая время** (всё отключается в настройках):
   - в строке/столбце/квадрате две пустые клетки → обе недостающие цифры пишутся в заметки обеих клеток;
   - одной цифре такой пары клетке мешает такая же цифра на доске → обе цифры встают на места;
   - пара из квадрата лежит в строке/столбце, где пустых три → третья клетка заполняется (и наоборот:
     пара из строки внутри квадрата, где пустых три);
   - восемь одинаковых цифр стоят → девятая встаёт сама;
   - пустых клеток осталось ≤ 5 (число настраивается) → игра дорешивает очевидное сама,
     только если доска заполняется целиком без противоречий;
   - поставленная цифра исчезает из заметок соседей.
   Вся автоматика выводит цифры **только из цифр на доске, не из заметок** — случайное касание в заметках
   не может породить неверную автоматическую цифру. Все её правила — уровня одиночек, поэтому трудный приём
   она перепрыгнуть не может: трудное место всегда остаётся игроку. Замер 03.10.2026 (трудные уровни,
   ходы в порядке решателя): автоматика заполняет ~20% пустых клеток без правил пар и ~60% с ними.
5. **Никакой рекламы, слежки и сетевых запросов**, кроме загрузки самих файлов игры.

## Устройство

- `js/core.js` — поле, быстрый перебор (проверка единственности решения), генератор.
- `js/logic.js` — 20 логических приёмов, уровни, оценка головоломки (`grade`).
- `js/generator.js` + `js/worker.js` — подбор головоломки нужного уровня прямо на телефоне, в фоне.
  Банка задач нет: генерация ~3 мс, примерно каждая четвёртая отбраковывается.
- `js/game.js` — правила и автоматика без экрана (тестируется в Node).
- `js/app.js`, `index.html`, `css/style.css` — экран. Вертикально: поле, под ним инструменты и цифры в ряд
  (у большого пальца). Горизонтально (планшет, повёрнутый телефон): поле слева, цифры 3×3 справа.
  Стоит на телефоне Oppo и на Android-планшете владельца.
- `sw.js`, `manifest.webmanifest`, `icons/` — установка и работа без интернета.

## Проверка

- `npm test` — тесты решателя (3000 головоломок, каждый шаг сверяется с ответом), автоматики
  и 300 партий робота верными ходами (ни одна автоматическая цифра не должна разойтись с ответом).
- `npm run stress` — большая проверка на 30 000 головоломок со счётом срабатывания каждого приёма.
- `npm start` — игра на компьютере: http://localhost:8480
- `npm run ui` (при запущенном `npm start`) — робот в браузере размером с телефон нажимает кнопки
  и фотографирует экраны в `tests/screens/` (браузер Playwright лежит в `D:\tools\ms-playwright`,
  путь в переменной `PLAYWRIGHT_BROWSERS_PATH`).

## Выпуск новой версии

1. Прогнать `npm test` и `npm run ui`.
2. **Поднять номер `CACHE` в `sw.js`** (иначе телефон может держать старые файлы).
3. `git push` — GitHub Pages обновится за минуту-две. На телефоне игра при запуске сама
   подхватывает новую версию и перезапускается на ней (начиная с версии v2).
   Пока сайт не опубликован — по кабелю: `npm start`, `adb reverse tcp:8480 tcp:8480`, открыть игру.
