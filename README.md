# Судоку

Судоку без рекламы и без угадывания. Работает в браузере и ставится на телефон как приложение.

**Играть:** https://slautin-av.github.io/sudoku/

- Каждую головоломку перед показом решает встроенный решатель — только логическими приёмами, как человек.
  Если без догадки не обойтись, головоломка выбрасывается. Решение всегда одно.
- Уровень определяется самым трудным приёмом, который понадобился: от скрытой одиночки
  до небоскрёба, W-Wing и раскраски.
- Ошибки не считаются и игру не заканчивают.
- Рутину игра делает сама: пары недостающих цифр в заметки, девятая одинаковая цифра, дорешивание последних клеток.

## Как поставить на Android

Открыть ссылку в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Для разработки

```
npm test      # проверки решателя и правил
npm start     # http://localhost:8480
```
